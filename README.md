## About Me

我是一名横跨 **全栈开发、嵌入式系统和音频 DSP** 的开发者，关注从底层设备驱动、通信协议到后端服务、Web 前端及移动应用的完整技术链路。

- **Full-Stack Engineering** — React、Go、Java、Spring Boot、Rust，关注模块化架构和系统性能。
- **Embedded & IoT** — STM32、FreeRTOS、BLE、无线通信、硬件接口及嵌入式固件开发。
- **Audio & DSP** — 数字音频处理、EQ、动态处理、无线音频和音频设备控制。
- **Infrastructure** — Linux、Docker、数据库、NAS、自托管服务与自动化部署。
- **AI Engineering** — AI Agent、开发自动化和智能工具集成。

> **Engineering Philosophy:** Simplicity · Performance · Reliability · Maintainability
